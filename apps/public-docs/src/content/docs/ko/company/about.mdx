## 미션

Newsfork는 AI 기반의 글로벌 정부 뉴스 인텔리전스 레이어입니다. 개발자, 분석가, 조직이 하나의 통합 API로 100개 이상 국가의 구조화된 정부 뉴스 데이터에 접근할 수 있도록 돕습니다.

## 만드는 것

- **Newsfork API** — 정부 뉴스 탐색, 검색, 메타데이터를 위한 REST API
- **News-V 스코어링** — 자체 관련성·품질 점수
- **CuFork Ads** — 디아스포라 뉴스 발행사를 위한 광고 플랫폼

## 회사

Newsfork는 News-Labs가 운영합니다. 제품 문의는 [www.newsfork.com](https://www.newsfork.com)을 방문하거나 [hello@newsfork.com](mailto:hello@newsfork.com)으로 메일을 보내 주세요.
