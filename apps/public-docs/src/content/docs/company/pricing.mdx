Official pricing for the Newsfork API. For the latest CTAs and trials, see [www.newsfork.com/pricing](https://www.newsfork.com/pricing/).

## Plans

| Plan | Price | Monthly requests | Highlights |
|------|-------|------------------|------------|
| **Free** | $0 | 1,000 | Keyword search, self-serve API keys, 10 rpm |
| **Pro** | $10/mo ($100/yr) | 50,000 | Semantic search + RAG, MCP tools, News-V, 100 rpm, 99.9% SLA |

## What counts as a request?

Any call to the Newsfork REST API — search, article fetch, feed query, semantic query, or MCP tool invocation — counts as one request. **Webhook deliveries do not count.**

## Coverage

Free and Pro include the full corpus. Filter with `?country=` and list sources with `/v1/sources`.

## Billing

- Pro includes a **14-day trial** on the first subscription.
- Payments are processed via **Stripe**.
- For volume or custom contracts, email [hello@newsfork.com](mailto:hello@newsfork.com).

## Not yet available

The knowledge agent endpoint (`/v1/knowledge/ask`) is not yet generally available. Use semantic search via `/v1/rag/query` on Pro.
